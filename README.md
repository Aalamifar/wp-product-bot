# ربات کپی محصول ووکامرس

## نصب (یک‌بار)

```bash
pip install playwright openpyxl
playwright install chromium
```

## قبل از اجرا — این‌ها را عصر توی شرکت چک کن

1. **آدرس لاگین:** آدرس دقیق `wp-login.php` سایت.
2. **کپچا/۲FA:** وقتی لاگین می‌کنی، غیر از یوزر/پسورد چیز دیگه‌ای هم می‌خواد؟
3. **دکمه‌ی «رونوشت»:** روی محصول قبلی راست‌کلیک کن روی دکمه → Inspect. ببین:
   - متن دقیق چیه (فارسی/انگلیسی)
   - تگش `<a>` است یا `<button>`
   - آیا `href` مشخصی داره یا با جاوااسکریپت/AJAX کار می‌کنه
4. **نوع ادیتور توضیحات:** وقتی محصول کپی‌شده باز می‌شه، ادیتور توضیحاتش:
   - یک جعبه‌ی متنی ساده با نوار ابزار بالا (Bold/Italic/...) = **کلاسیک (TinyMCE)**
   - یا هر پاراگراف/خط داخل یک کادر جدا با دستگیره‌ی کوچک کنارش = **Gutenberg**
5. **نمونه متن توضیحات:** یک محصول رو باز کن، متن کامل توضیحاتش رو کپی کن و برام بفرست
   (متن ساده کافیه، عکس لازم نیست) تا تابع `build_new_description` رو دقیق کنم.
6. **فایل اکسل واقعی:** مسیرش رو توی `EXCEL_PATH` بذار، و مطمئن شو نام ستون‌ها/ترتیبشون
   دقیقاً با چیزی که در کد فرض کردم (A تا H طبق عکسی که فرستادی) یکی است.

## اجرا

```bash
python wp_product_bot.py
```

اولین بار حتماً:
- `HEADLESS = False` بمونه تا با چشم ببینی چی کار می‌کنه.
- فقط ۱-۲ ردیف توی اکسل تستی بذار، نه کل لیست.
- توی `publish()` قبلش یه بار دستی چک کن که `#publish` واقعاً همون دکمه‌ی
  انتشار سایت شماست (ممکنه آی‌دی/کلاس فرق داشته باشه).

## جاهایی که باید بعد از دیدن سایت واقعی عوض کنی

همه با `# TODO` توی فایل `wp_product_bot.py` علامت‌گذاری شده‌اند:
- `WP_LOGIN_URL`, `WP_USERNAME`, `WP_PASSWORD`
- `TEMPLATE_PRODUCT_EDIT_URL`
- سلکتور دکمه‌ی «رونوشت»
- سلکتور اسلاگ و دکمه‌ی OK
- منطق `build_new_description` (بعد از فرستادن نمونه متن)
- سلکتور دکمه‌ی انتشار

هر خطا/رفتار عجیبی که موقع اجرا دیدی رو برام بفرست تا دقیقش کنیم.
